01 · PROJECT IDENTITY

외부 서비스를 만들기 전에
package ID부터 확정합니다.

  1. product name을 새 게임 이름으로 변경합니다.
  2. Android application ID를 고유한 값으로 변경합니다.
  3. company와 version/versionCode를 확인합니다.
  4. portrait, minimum API 25, target API 35가 게임 요구와 맞는지 확인합니다.
복사 금지

다른 게임의 Firebase 설정이나 production ad ID를 재사용하지 않습니다. 서비스의 Android 앱 등록은 package ID와 한 쌍입니다.

02 · FIREBASE

App · Analytics · Crashlytics.

기준 버전은 Firebase Unity SDK 13.7.0입니다. Asset package와 Firebase UPM 설치 방식을 한 프로젝트에서 섞지 않습니다.

  1. 새 게임 소유의 Firebase project를 생성하거나 선택합니다.
  2. 새 application ID로 Android 앱을 등록합니다.
  3. google-services.json을 내려받아 Assets/에 둡니다.
  4. Mobile Template > Build Sample Scenes를 실행해 bootstrap asset에 Firebase 설정 존재 여부를 다시 기록합니다.
  5. Google Analytics와 Crashlytics를 활성화합니다.
  6. External Dependency Manager Android resolver를 실행합니다.
  7. 개발 빌드에서 readiness event와 deliberate non-fatal exception을 확인합니다.

설정 파일은 Git에서 제외됩니다. 파일이 없어도 base template은 unavailable 상태로 계속 동작합니다.

03 · GOOGLE MOBILE ADS & UMP

샘플 ID로 시작하고,
릴리스 전에 모두 교체합니다.

기준 버전은 Google Mobile Ads Unity Plugin 11.0.0입니다.

  1. 새 package ID로 AdMob Android 앱을 만듭니다.
  2. banner, interstitial, rewarded, rewarded-interstitial, app-open unit을 만듭니다.
  3. GoogleMobileAdsSettings의 sample app ID를 교체합니다.
  4. AdMobSettings의 다섯 sample ad-unit ID를 교체합니다.
  5. AdMob Privacy & messaging에서 지역별 메시지를 구성합니다.
  6. test device에서 consent, privacy options와 모든 광고 형식을 검증합니다.
  7. signed release 직전에만 template test mode를 끕니다.
04 · SIGNING

키는 프로젝트가 아니라
소유자가 보관합니다.

템플릿에는 keystore와 암호가 없습니다. 게임별 upload keystore를 저장소 밖에 만들고 Player Settings에서 로컬 경로를 연결합니다. alias password, keystore.properties, signing.properties는 커밋하지 않습니다.

05 · VALIDATION PROFILES

목적에 맞는 실패 기준.

프로필허용차단

Unity에서 시작한 모든 Android build도 Development 여부에 따라 알맞은 preprocessor validation을 실행합니다.

06 · BUILD

샘플 기반의 실행 항목.

  • Validate Template Project — 깨끗한 스타터 확인
  • Validate Development Configuration — 게임별 ID와 test ads 확인
  • Validate Release Configuration — production 조건 확인
  • Build Sample Scenes — 명시적으로 연결된 sample asset 재생성
  • Build Development Android APK — 개발 IL2CPP APK 생성
폰트 주의

포함된 LiberationSans TMP font는 한국어 glyph를 포함하지 않습니다. 한국어 locale을 사용하면 해당 glyph를 가진 TMP font 또는 fallback을 지정해야 합니다.
