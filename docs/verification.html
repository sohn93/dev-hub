03 · FINDINGS

검증이 실제로 찾아낸 것.

Google Mobile Ads Android payload

첫 Android build에서 pruning 과정 중 누락된 vendor manifest 경로 4개를 확인했습니다. 필요한 파일을 복구하고 embedded manifest를 Google sample app ID로 정규화한 뒤 반복 build가 통과했습니다.

Core Audio dependency

Core-only smoke project가 Unity built-in Audio module의 미선언 의존성을 드러냈습니다. Core package manifest에 com.unity.modules.audio 1.0.0을 추가한 뒤 SDK 없는 smoke compile이 통과했습니다.

SDK version label

복사된 Firebase payload에는 13.7.0과 13.8.0 label이 섞여 있습니다. 선택된 App/Analytics/Crashlytics assembly는 Unity compile과 APK packaging을 통과했지만, 기기 runtime delivery는 확인하지 않았습니다.

04 · REMAINING

기기가 생기면 이어서 확인할 것.

  1. USB debugging 기기 또는 emulator를 연결합니다.
  2. 개발 APK를 설치하고 startup, navigation, popup, Back, safe-area, preference 흐름을 확인합니다.
  3. 게임별 Firebase 설정을 추가한 뒤 Analytics DebugView와 Crashlytics 전달을 확인합니다.
  4. UMP와 모든 광고 형식을 test device에서 확인하고 근거를 이 원장에 추가합니다.
