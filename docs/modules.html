01 · CORE

com.heosigames.mobile-template.core

SDK 없이도 컴파일되는 앱 셸과 서비스 계약입니다.

영역주요 책임
Bootstrap순차 서비스 초기화, timeout, 결과 기록, initial screen 진입
Navigationscreen history, popup LIFO, Android Back, safe area
Lifecyclepause/resume 신호 전달
LocalizationCSV lookup과 TMP text 연결
AudioBGM/SFX preference와 caller-provided clip 재생
Servicesanalytics, crash, ads contract와 null 구현

직접 의존성은 Unity UI, TextMesh Pro, Input System, built-in Audio module입니다.

02 · FIREBASE ADAPTER

com.heosigames.mobile-template.firebase

Core의 analytics와 crash-reporting 계약을 Firebase App, Analytics, Crashlytics에 연결합니다. Firebase Auth와 Google Sign-In은 포함하지 않습니다.

  • Firebase dependency 확인과 복구 가능한 unavailable 상태
  • App, Analytics, Crashlytics 준비 상태 분리
  • 분석 event와 parameter를 SDK-neutral 값에서 변환
  • non-fatal exception과 custom key 전달
선행 조건

소비 프로젝트에 Firebase Unity SDK App, Analytics, Crashlytics assembly가 설치되어야 adapter package가 컴파일됩니다. vendor SDK는 패키지에 재배포하지 않습니다.

03 · GOOGLE MOBILE ADS ADAPTER

com.heosigames.mobile-template.google-mobile-ads

Core 광고 계약을 Google Mobile Ads와 UMP에 연결합니다. 동의 가능 상태가 광고 초기화와 요청의 gate가 됩니다.

지원 형식계약 동작
Bannerload, show, hide, destroy
Interstitialload와 1회 completion 보장 show
Rewarded광고 결과만 반환; 실제 게임 보상은 외부 정책
Rewarded interstitialreward callback과 종료 결과 분리
App openload와 foreground 정책에 사용할 show
UMPconsent refresh, form, privacy options
04 · PUBLIC CONTRACTS

게임 코드가 바라볼 인터페이스.

  • IAnalyticsService — event와 parameter 기록
  • ICrashReportingService — exception, log, custom key
  • IAdService — 준비 상태, load/show, 광고 결과
  • IAppBootstrapService — startup service 등록
  • ILocalizationService — locale과 key lookup
  • IAudioService — preference와 clip playback
05 · PROJECT-OWNED

패키지 바깥에 남겨둔 것.

scene, prefab, localization CSV, AppRuntimeSettings, AdMobSettings, Firebase configuration, vendor SDK binaries, Android resolver output, Player Settings는 게임 프로젝트가 소유합니다. 이 경계 덕분에 패키지가 특정 application ID나 production credential을 품지 않습니다.
